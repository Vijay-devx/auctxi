# User Management Guide (Admins Only)

As an Admin, you are responsible for maintaining the integrity of the platform.

## Managing Users
- Admins can view all registered users across the platform.
- Users can be banned or suspended if they violate platform rules.
- A user's role (Manager or Client) is assigned at registration and cannot be freely changed without Admin intervention.

## Global Rules
- Only Admins can create "Global Auction Rule Templates".
- These templates define constraints like Minimum Base Price, Maximum Purse Limit, and Auction Duration limits.
- Managers must select one of these approved templates when creating a new auction.
